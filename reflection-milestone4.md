# Reflection - Milestone 4

## **Usability of the App**

Throughout the development of our dashboard, usability is our key focus. Overall, the app is user-friendly, but there are areas for improvement. 
The interactive elements, such as selecting municipalities and comparing Gini coefficients across years, function well. 

However, some usability issues remain, such as the map not automatically enlarging when opened, making it less convenient for users to explore.

## **Common Themes in Feedback**

A few recurring themes have emerged in the feedback we have received:

1. **Visual Clarity and Emphasis**
   - Some numbers, especially on the Gini coefficient card, are not prominent enough.
   - Increasing font size and adjusting colors can enhance readability.
2. **Optimized Use of Space**
   - The legend placement in charts can be optimized by moving it to the top, reducing empty space.
3. **Better Explanation of Metrics**
   - Gini coefficient definition and the map explanations could be clearer and more noticeable.
   - Enlarging these sections could help improve understanding.
4. **Interactivity Enhancements**
   - Some users have expressed interest in automatic map enlargements upon opening the dashboard. This would improve visibility and allow for a better exploration of geographical data.

## **Valuable Insights** 

One of the most useful insights was that small UI changes significantly impact user experience. 
For example, allowing the map to automatically enlarge would streamline navigation, and repositioning the legend could make better use of screen space.

Moving forward, we plan to implement these refinements to improve usability and engagement.

## **Next Steps**

To address the feedback, we will implement the following improvements:

- Enable automatic map enlargement when users open the dashboard.
- Adjust the color and font size of number cards for better visibility.
- Relocate the legend on charts to optimize space usage.
- Expand the explanation section for the Gini coefficient and map interpretations.

By integrating these refinements, we aim to enhance the dashboard’s usability and effectiveness, ensuring that users can derive insights efficiently and with ease. 
These improvements will contribute to a more seamless user experience, making the dashboard an even more powerful tool for data visualization and analysis.
