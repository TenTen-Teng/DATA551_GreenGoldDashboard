# **Reflection - Milestone 4**  

## **Usability of the App**  

Throughout the development of our dashboard, usability has remained our key focus. Overall, the app is user-friendly, with interactive elements that allow users to seamlessly explore data, such as selecting municipalities and comparing Gini coefficients across years.  

However, some usability issues remain, such as the map not automatically enlarging when opened, making it less convenient for users to explore. Additionally, while we have improved data presentation with summary cards, further refinements are needed to ensure clarity and accessibility of information.

## **Common Themes in Feedback**  

A few recurring themes have emerged in the feedback we have received:  

1. **Visual Clarity and Emphasis**  
   - Some numbers, especially on the Gini coefficient card, are not prominent enough.  
   - Increasing font size and adjusting colors can enhance readability.  
   - The summary cards have improved clarity but could further emphasize percentage changes.  

2. **Optimized Use of Space**  
   - The legend placement in charts can be optimized by moving it to the top, reducing empty space.  
   - The redesigned summary cards help improve visual structure, but overall layout adjustments could make information easier to digest.  

3. **Better Explanation of Metrics**  
   - The inclusion of tooltips in the summary cards has been a valuable addition, providing users with clear explanations of the Gini coefficient changes.  
   - The definition of the Gini coefficient and its significance should be more prominently displayed to aid users unfamiliar with the metric.  
   - Expanding these sections could improve understanding and make the app more informative.  

4. **Interactivity Enhancements**  
   - Some users have expressed interest in automatic map enlargements upon opening the dashboard. This would improve visibility and allow for better exploration of geographical data.  
   - The summary cards displaying the percentage change in Gini across avocado and non-avocado municipalities have enhanced usability, making it easier to interpret the impact of trade policies.  

## **Valuable Insights**  

One of the most valuable insights gained from this iteration is that small UI changes significantly impact user experience. Enhancing the way data is presented, such as using percentage changes in Gini rather than absolute values, has made the insights more intuitive.  

Additionally, the inclusion of tooltips has reinforced the importance of providing contextual information without overwhelming users. This feature ensures that users can engage with the dashboard dynamically, accessing explanations only when needed.  

Moving forward, we plan to implement further refinements to enhance usability and engagement while maintaining a balance between interactivity and clarity.  

## **Next Steps**  

To address the feedback, we will implement the following improvements:  

- **Enable automatic map enlargement** when users open the dashboard to enhance geographical exploration.  
- **Adjust the color and font size of number cards** for better visibility, ensuring key data points stand out.  
- **Relocate the legend on charts** to optimize space usage and improve readability.  
- **Expand the explanation section for the Gini coefficient and map interpretations**, making it more accessible to users unfamiliar with the metric.  
- **Refine the summary cards further**, potentially integrating a bigger font size and a better color to make trends immediately apparent.  

By integrating these refinements, we aim to improve the dashboard’s usability and effectiveness, ensuring that users can derive insights efficiently and with ease. These improvements will contribute to a more seamless user experience, making the dashboard an even more powerful tool for data visualization and analysis.
